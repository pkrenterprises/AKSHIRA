# AKSHIRA Order Enquiry Website

Static responsive website for AKSHIRA by PKR Enterprises.

## Preview
Open `index.html` in a modern browser.

## Deploy
Upload this folder to a Cloudflare Pages project (or connect its Git repository). Use no build command and `.` as the output directory. Review the included `wrangler.toml` against your current Cloudflare/Wrangler setup.

## Enquiry workflow
The form prepares a WhatsApp message for +91 93816 61029. The visitor must review and send it. The site does not process payments or confirm orders.

A selected logo/reference file is not automatically uploaded; the visitor must attach it manually in WhatsApp. No backend, database, file storage or admin dashboard is included.

Customisation, availability, minimum order quantities, prices and delivery timelines must be confirmed by AKSHIRA.
